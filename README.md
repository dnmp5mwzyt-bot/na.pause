# На паузе — сайт кофейни

Одностраничный сайт кофейни «На паузе» (Москва, Челябинская ул., 19 к4).

Статика без сборки: откройте `index.html` в браузере.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка страницы |
| `styles.css` | стили, фирменная палитра |
| `script.js` | вкладки меню, мобильная навигация, появление блоков при скролле |
| `assets/` | логотип и фотографии |

## Фирменный стиль

Палитра снята с логотипа: синий `#253382` и пудровый `#E3D4CF`.
Шрифт — [Onest](https://fonts.google.com/specimen/Onest).

## Что нужно уточнить

* Время закрытия в блоке «Контакты» — сейчас указано только открытие в 8:00.
* Цены в меню взяты с Яндекс Карт и могут быть неактуальны.
